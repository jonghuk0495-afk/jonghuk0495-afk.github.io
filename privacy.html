MyWorkDesk 개인정보처리방침

시행일: 2026-11-09 · 홈으로

1. 누가 사용하나요

MyWorkDesk는 운영자 본인만 자신의 Windows PC에서 사용하는 개인용 앱입니다. 다른 사용자에게 제공하지 않습니다.

2. 어떤 Google 데이터를 읽나요

사용자가 직접 연결한 경우에만 다음 읽기 전용 권한을 사용합니다.

  • 캘린더 목록 보기 (calendar.calendarlist.readonly)
  • 일정 보기 (calendar.events.readonly)

일정의 제목, 시간, 장소, 참석 응답 상태 등을 읽습니다. 캘린더에 쓰거나 일정을 수정·삭제하지 않습니다.

3. 데이터는 어디에 저장되나요

불러온 일정은 사용자 PC의 앱 데이터 폴더에만 저장됩니다. 운영자의 서버는 없으며 일정 데이터를 다른 곳에 업로드하거나 판매·공유하지 않습니다. 로그인 토큰은 Windows가 제공하는 암호화 저장소로 보호해 같은 PC에 저장합니다.

4. AI 기능을 켠 경우

사용자가 앱의 선택 기능인 AI 정리 기능을 켜고 요청 버튼을 누르면, 계획을 세우기 위해 작업 이름과 오늘·내일의 일정 시간(설정에 따라 일정 제목 포함)이 사용자 본인의 ChatGPT 계정을 통해 OpenAI로 전송될 수 있습니다. 이 기능은 기본적으로 꺼져 있고, 일정 제목을 보내지 않도록 설정할 수 있습니다. Google 데이터를 광고나 AI 모델 학습 목적으로 사용하지 않습니다.

5. 보관과 삭제

앱에서 Google 연결을 해제하면 앱에 저장된 일정 사본과 로그인 정보가 삭제되고 권한이 취소됩니다. Google 계정 → 보안 → 서드 파티 액세스에서도 언제든 권한을 취소할 수 있습니다.

6. Google API 서비스 사용자 데이터 정책

MyWorkDesk가 Google API에서 받은 정보의 사용과 다른 앱으로의 전송은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.
